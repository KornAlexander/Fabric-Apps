# 01: pbi-fixer

*Post 1 of 15 in the Fabric Apps series. One per weekday.*

## Post text

```text
You can fix a Power BI semantic model without opening Power BI Desktop.

Power BI Fixer reads your model and report straight out of Fabric, runs Best Practice Analyzer rules against them, and applies the fix. In the browser. Nothing to install.

Model explorer with inline TMDL. Memory analyzer, so you can see which column is actually costing you. A DAX editor with a formatter. Unused-object cleanup, display folders, descriptions, field parameters.

The interesting part is not the UI. It is that a Fabric App can hold a privileged server-side function and still run entirely as the signed-in user.

Source, and always the latest version:
https://github.com/KornAlexander/Fabric-Apps/tree/main/fabric-admin/pbi-fixer
```
