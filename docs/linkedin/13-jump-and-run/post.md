# 13: jump-and-run

*Post 12 of 13 in the Fabric Apps series, one per weekday.*

## Post text

```text
One hundred levels, and every completed run lands in a Fabric SQL table.

A single-file HTML5 Canvas platformer inside a Fabric-authenticated app. Ten themed stages, progress saved per player, on-screen controls so it works on a phone.

The game reports each finished run to the host page, which writes it to a typed entity through the Rayfin data client.

A game is an unusually honest load test for an app platform. It fails visibly.

App page: https://kornalexander.github.io/Fabric-Apps/apps/jump-and-run/
```
