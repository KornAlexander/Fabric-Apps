# 14: ibcs-trainer

*Post 13 of 13 in the Fabric Apps series, one per weekday.*

## Post text

```text
You learn a charting standard faster by destroying bad charts than by reading the rules.

IBCS Trainer is a platformer where each level teaches one IBCS notation rule. Pie charts explode. The wrong chart for a time series has to go.

It is the same standard you would otherwise learn from a 200-page manual, in the order you would actually meet the problems.

Scores persist to Fabric SQL, so a team can run it as a shared exercise.

App page: https://kornalexander.github.io/Fabric-Apps/apps/ibcs-trainer/
```
