# Games and Learning

Fabric is usually shown as a data platform. These are the apps that show it is also a
runtime: a strategy game, a 90s shooter, a platformer and an IBCS trainer, all deployed
the same way an analytics app is.

| App | What it is |
|---|---|
| [doom](doom/) | see its README |
| [fabric-empires](fabric-empires/) | see its README |
| [ibcs-trainer](ibcs-trainer/) | see its README |
| [jump-and-run](jump-and-run/) | see its README |
| [paragliding-insights](paragliding-insights/) | see its README |

Every app deploys with `npx rayfin up`. See the [repository README](../README.md) for the full index.
